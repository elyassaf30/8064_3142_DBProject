## על המערכת

מסד נתונים לאגף רווחת הסטודנט: מעונות, חדר אוכל, חדר כושר ושיעורי עזר.

## הרצת מסד הנתונים

המסד רץ בדוקר: PostgreSQL ו-pgAdmin.

1. ליצור בתיקייה הראשית קובץ `.env` עם חמשת המשתנים (הקובץ לא נשמר בגיט):

</div>

```
DB_USER_SECRET=...
DB_PASSWORD_SECRET=...
DB_NAME_SECRET=...
PGADMIN_EMAIL=...
PGADMIN_PASSWORD=...
```

<div dir="rtl">

2. להריץ:

</div>

```
docker compose up -d
```

<div dir="rtl">

בהרצה הראשונה דוקר יוצר את הטבלאות ומכניס את הנתונים מתוך הקבצים `createTables.sql` ו-`insertTables.sql` שבתיקיית "שלב א".
pgAdmin זמין בכתובת `http://localhost:8080`.

אחרי שינוי בקבצים צריך למחוק את המסד הישן ולהרים מחדש:

</div>

```
docker compose down -v
docker compose up -d
```
